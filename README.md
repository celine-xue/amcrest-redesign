# Amcrest E-commerce Redesign

Independent course project by Mengmeng Xue. Career fair baseline: October 14, 2026.

An interactive demo built from the supplied desktop and mobile Figma design exports. This is a conceptual redesign with no client engagement with Amcrest. Shopping, cart, cloud-plan and support interactions are demonstration states; no payments, subscriptions or messages are submitted.

Open `index.html` through a static web server, or visit the published GitHub Pages site. The case study is in `case-study/`.
